## Local Development

- Run `start_dev.sh` for an HTTP server
- Or, use Firefox Local Mode in the DevTools settings
  - Pick whichever app in docs to host by choosing its folder

## Deployment

Any changes to `main` branch for the Github remote will be automatically deployed within a couple minutes and `/docs` is the page hosted
