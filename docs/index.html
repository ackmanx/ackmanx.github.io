Install new OS
        
- First boot
    - Skipped Apple ID sign in
- Clean up dock
- Open Terminal
    - Run `git` to prompt for Xcode Developer Tools. This is mandatory and if you don’t do it then later when installing Homebrew it will do it anyway
- Open Safari
    - Log into password manager for later
    - Log into Github to get at the `config` repo
    - Register a new SSH key to get access to clone the repo
- Clone `config`
- Open it and look at MacOS fresh install guide to continue
